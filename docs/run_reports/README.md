# Run reports

What happened when an experiment was run, written for the experiment's owner when the person who ran
it is not the one analysing it. Each report covers:
- what was run, on which machine and with which settings;
- the choices made between steps;
- a time breakdown, to judge whether similar runs are feasible;
- every error, with the fix and whether it touches the results;
- what the console output shows, and what it hides.

The results themselves and their analysis belong in `docs/experiments/`.
